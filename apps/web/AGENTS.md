# AGENTS.md

Rules for `apps/web`. Also follow the repository [AGENTS.md](../../AGENTS.md) and [docs/architecture.md](../../docs/architecture.md).

## When to use

Use this file when you edit the site, the Worker, or `lib/`.

## Rules

- Put page behavior in `src/`. Put route planning in `lib/server/config.ts` and `worker/index.ts`.
- Do not fetch MapTiler from a component. The browser calls `/api/config` and, only when that payload says a key exists, `/api/basemap/style.json`.
- `MAPTILER_API_KEY` stays a Worker secret. `/api/config` returns `maptiler: true` and no key. The rewritten style must not contain the key.
- Do not declare that secret in `wrangler.jsonc`. An empty key must still build.
- Do not log upstream URLs.
- Accept only `GET` and `HEAD` on `/api/*`.
- Config responses are `cache-control: no-store`. Upstream tile responses may be cached for a day. Errors are plain text.
- Depth colors and PMTiles source URLs are built in `src/layers.ts` from `@fishy/core`. Do not hard-code a second copy of the protocol rules in the component.
- After a binding or var change, run `pnpm exec wrangler types --include-runtime false` from this directory and commit `worker-configuration.d.ts`.
- The dev sample archives in `public/samples/` are generated by `just pipeline-sample`. Do not hand-edit them.

## Commands

From this directory:

```bash
pnpm test
pnpm run typecheck
pnpm run build
pnpm exec wrangler types --include-runtime false --check
```

Lint runs from the repository root (`pnpm run lint`). `just check` includes these steps.

## Failures

- Non-`/api` requests that reach the Worker return 404. Assets still serve the single-page app.
- A missing MapTiler key on `/api/basemap/*` returns 404 `basemap unavailable`.
- Upstream network failure returns 502 `upstream failed`.
